# 📝 To-Do List - Projeto de Lista de Tarefas

Este é um projeto simples de **To-Do List** (lista de tarefas) desenvolvido com **React.js**, criado com o objetivo de praticar e consolidar conhecimentos em **componentização**, **manipulação de estado** e **eventos** em React.

---

## 🚀 Funcionalidades

- ✅ Adicionar novas tarefas
- 🗑️ Remover tarefas
- 📌 Editar tarefas

---

## 🧠 Objetivos do projeto

Este projeto foi criado como parte do meu processo de aprendizado em React. Com ele, pratiquei:

- Uso de `useState` e `useEffect`
- Manipulação de formulários
- Estruturação de componentes
- Estilização com CSS
- Organização de código para legibilidade

---

## 🛠️ Tecnologias utilizadas

- React.js
- JavaScript (ES6+)
- CSS3
- HTML5
